## 0. 요약

배터리 팩을 **직육면체**로 단순화하고, 그 **표면**에 두 종류의 경계조건을 부과한다.

| # | 소스 | FDS 구현 | 1D에서 받을 것 |
|---|------|----------|----------------|
| A | 화학 분해 발열 | 표면 열유속 `&SURF NET_HEAT_FLUX + RAMP_Q` | `Q_chem(patch, t)` [kW] |
| B | Vent gas 분출 (연소는 FDS가 계산) | `&SURF MASS_FLUX(N) + RAMP_MF(N) + TMP_FRONT + RAMP_T` | `ṁ(t)`, `Y_i(t)`, `T_vent(t)` |
| C | 차체·타이어·내장재 | `&OBST + &MATL` 열분해 | (1D 불필요) |

**두 가지 절대 원칙**

1. **§1 이중계상 금지** — `Q_chem`에 vent gas 연소열이 포함되면 안 된다.
2. **§2 열원 면적 하한** — 열유속 부과 면은 **실제 vent 오리피스가 아니라 팩 표면**이어야 한다. 오리피스에 부과하면 수치적으로 파탄난다.

## 1. [원칙 1] 에너지 분해 규약 — 이중계상 방지

```
HRR_exp(t) = Q_chem(t)  +  Q_gas(t)  +  Q_veh(t)
              │            │             └ 차체/타이어/내장재 연소 (FDS 계산)
              │            └ vent gas 연소 (FDS 계산)
              └ 고체상 화학 분해 반응열 (1D 제공)
```

| 항 | 계산 주체 | 1D 제공 |
|----|-----------|---------|
| `Q_chem` | 1D 제공 → FDS 표면 열유속으로 부과 | ✅ 필수 |
| `Q_gas` | FDS 직접 계산 (조성 × 연소열 × 국소 O₂) | ❌ 조성·유량만 |
| `Q_veh` | FDS 직접 계산 | ❌ |

### 1.1 `Q_chem` 정의 확정 사항

1. **기상 연소열 제외.** 팩 내부에서 이미 연소한 몫이 있다면 `Q_chem`에 포함하고, 대신 소모된 가스는 vent 유량에서 빼고 생성물(CO₂/H₂O)로 조성에 반영.
2. **셀 승온 현열을 뺀 순 방출량**일 것. 총 반응열을 주면 FDS에서 팩이 이중으로 뜨거워짐.
3. **Vent gas가 운반하는 현열과 분리할 것.**
   `T_vent = 600 °C`, `ṁ = 0.05 kg/s`이면 가스가 이미 `ṁ·cp·ΔT ≈ 0.05 × 1.2 × 580 ≈ 35 kW`를 domain으로 들여온다.
   → `Q_chem`은 **표면에서 전도·복사로 나가는 열만** (가스 현열 제외) 이어야 한다.
4. **트리거 히터 전력은 별도 채널**로 분리.

## 2. [원칙 2] 열원 부과 면의 면적 하한 ⚠️

`Q_chem`을 실제 vent 오리피스 면적에 균등 분배하면 열유속이 비현실적으로 커진다.

| 부과 면 | 면적 | Q=250 kW | Q=500 kW | Q=1000 kW |
|---------|------|----------|----------|-----------|
| 실제 vent 오리피스 합 | 0.01 m² | 25,000 kW/m² (4309 °C) | 50,000 (5176 °C) | 100,000 (6207 °C) |
| 모듈 상부면 1개 | 0.53 m² | 470 kW/m² (1424 °C) | 940 (1745 °C) | 1881 (2127 °C) |
| 팩 상부면 전체 | 3.19 m² | 78 kW/m² (811 °C) | 157 (1016 °C) | 314 (1260 °C) |
| 팩 전 표면 | 7.47 m² | 33 kW/m² (603 °C) | 67 (769 °C) | 134 (966 °C) |

※ 괄호 안은 복사평형 벽온도 `T = (q″/σ)^¼`. 참고로 대형 풀화재 표면 열유속이 대략 100~200 kW/m² 수준.

**결론**
- 열유속 부과 면 = **팩 직육면체의 표면 (상부면 또는 전 표면)**
- Vent gas 분출 면 = **실제 vent 위치** (별도 SURF)
- 두 면을 **분리**해야 하며, 이는 FDS 제약 때문이기도 하다 (`NET_HEAT_FLUX`와 `TMP_FRONT`는 동시 지정 불가, §4.1)
- 설계 목표: `q″_max ≲ 500 kW/m²`, 최소한 `≲ 1000 kW/m²`

## 3. [핵심] 공간 해상도 — 비균등 분포 처리

### 3.1 원칙: **1D 노드 해상도가 FDS 경계조건 해상도의 상한**

1D 모델이 모듈 단위로 풀면, FDS에 셀 단위 분포를 넣을 수 없다 (없는 정보를 만들어내는 것). 따라서 확정 순서는:

```
1D 노드 구성 확인  →  노드→표면패치 매핑 규칙 결정  →  패치 정의  →  데이터 요청
```

### 3.2 해상도 옵션과 비용

팩 치수 2.20 × 1.45 × 0.15 m 기준, 전 표면 7.47 m².

| 옵션 | 패치 수 | 필요 SURF/RAMP | 5000스텝 데이터점 | 판정 |
|------|---------|----------------|-------------------|------|
| L0 전체 균일 | 1 | 1 | 5,000 | 1차 테스트용 |
| L1 면 단위 (6면) | 6 | 6 | 30,000 | 최소 비균등 |
| **L2 모듈 상부면 (6모듈)** | **6** | **6** | **30,000** | **권장 기본** |
| L3 모듈 × 노출면 (6×5) | 30 | 30 | 150,000 | 상세, 실행 가능 |
| L4 셀 단위 (171셀) | 171 | 171 | 855,000 | 1D가 셀 단위로 풀 때만 |
| L5 δx=5 cm 격자 | 2,989 | 2,989 | 15,000,000 | ❌ 비현실적 |
| L6 δx=2.5 cm 격자 | 11,959 | 11,959 | 60,000,000 | ❌ 비현실적 |

**권장: L2 (모듈 상부면 단위)로 시작 → 필요시 L3으로 확장.**
L5 이상은 FDS 입력파일에 수천 개의 `&SURF`/`&RAMP`가 필요해 실무적으로 불가능하며, 1D가 그 해상도의 정보를 갖고 있지도 않다.

### 3.3 패치 크기 하한

패치는 **FDS 격자 셀보다 작을 수 없다.** `δx = 2.5 cm`이면 패치 최소 변 길이 ≥ 2.5 cm.
권장: 패치 한 변 ≥ 3~4 셀 (열유속이 셀 단위로 튀는 것을 방지).

### 3.4 직육면체 표면 패치 정의 규약

팩 직육면체의 6면에 대해 면 ID를 부여하고, 각 면을 격자 분할한다.

```
면 ID:  TOP (+z),  BOT (-z),  XN (-x),  XP (+x),  YN (-y),  YP (+y)
패치 ID: <면ID>_<i>_<j>     예) TOP_02_01
```

패치 정의 파일 `patches.json`:

```json
{
  "pack_box": {"xb": [0.60, 2.80, 0.30, 1.75, 0.25, 0.40]},
  "patches": [
    {"id": "TOP_01_01", "face": "TOP", "xb": [0.60, 0.97, 0.30, 1.02, 0.40, 0.40],
     "area_m2": 0.266, "linked_1d_node": "M01"},
    {"id": "TOP_01_02", "face": "TOP", "xb": [0.60, 0.97, 1.02, 1.75, 0.40, 0.40],
     "area_m2": 0.270, "linked_1d_node": "M02"}
  ]
}
```

> 패치 분할이 1D 노드와 1:1이면 `linked_1d_node`로 매핑이 끝난다.
> 1D 노드 하나가 여러 패치에 걸치면 **면적 비례 분배**를 기본 규칙으로 하고, 다른 규칙이 필요하면 명시할 것.

## 4. FDS 매핑

### 4.1 화학 발열 → 표면 열유속

FDS의 두 가지 선택지:

| 키워드 | 동작 | 총 에너지 제어 | `TMP_FRONT` 병용 |
|--------|------|----------------|------------------|
| `NET_HEAT_FLUX` | 복사+대류 **합**이 지정값이 되도록 벽온도를 역산 | ✅ 정확 | ❌ **불가** |
| `CONVECTIVE_HEAT_FLUX` | **대류분만** 지정값. 복사는 `EMISSIVITY`와 벽온도로 별도 결정 | ⚠️ 복사분 추가됨 | ✅ 가능 |

**권장: `NET_HEAT_FLUX`** — `Q_chem`이 정확히 domain에 들어가고, 복사/대류 분배는 FDS가 물리적으로 처리한다 (차체 착화 예측에 중요한 복사 피드백이 자동 확보됨).

`TMP_FRONT`를 못 쓰므로, **vent gas 분출 면과 반드시 분리**해야 한다.

```fortran
! ── 열원: 팩 상부면 패치 (모듈 M01 담당) ──
&SURF ID='qdot_TOP_01_01', COLOR='ORANGE',
      NET_HEAT_FLUX=470., RAMP_Q='q_M01' /     ! kW/m2 = Q_chem_max(M01)/A_patch

&VENT XB=0.60,0.97,0.30,1.02,0.40,0.40, SURF_ID='qdot_TOP_01_01' /

&RAMP ID='q_M01', T=0.0, F=0.000 /
&RAMP ID='q_M01', T=0.1, F=0.026 /
...

! ── Vent gas: 실제 오리피스 위치 (별도 면) ──
&SURF ID='vent_V01',
      SPEC_ID(1:5)='CARBON DIOXIDE','CARBON MONOXIDE','HYDROGEN','METHANE','ETHYLENE',
      MASS_FLUX(1:5)=m1,m2,m3,m4,m5,
      RAMP_MF(1)='mf_V01_CO2', RAMP_MF(2)='mf_V01_CO', ...
      TMP_FRONT=600., RAMP_T='T_V01' /

&VENT XB=..., SURF_ID='vent_V01' /
```

- `NET_HEAT_FLUX = Q_chem_max(patch) / A_patch` [kW/m²]
- `RAMP_Q`의 `F = Q_chem(patch, t) / Q_chem_max(patch)` (0~1 정규화)
- vent 오리피스 셀은 열유속 패치에서 **제외**하거나, 겹쳐도 되도록 vent를 팩 측면에 두는 등 배치로 회피

**검증:** `_hrr.csv`의 `Q_COND`·`Q_RADI` 합이 `∫Q_chem dt`와 일치하는지 소규모 테스트 케이스로 확인할 것.

### 4.2 Vent gas 연소 (`&REAC`)

- **방안 B (권장)**: 가연종별 개별 `&SPEC` + `&REAC`. 조성 시간변화가 발열량에 자동 반영.
- **방안 A (단순화)**: 시간평균 조성의 lumped fuel 1종. 1차 해석용.

→ 결정에는 §5.3의 "조성이 시간에 따라 유의하게 변하는가" 답변이 필요.

### 4.3 차체 (1D 불필요)

| 부위 | 재질 | 상태 |
|------|------|------|
| 차체 패널 | Steel | **비가연** — `DENSITY, CONDUCTIVITY, SPECIFIC_HEAT`만 |
| 타이어 | Rubber | 가연 — `A, E, HEAT_OF_REACTION, HEAT_OF_COMBUSTION, NU_SPEC` 추정 |
| 시트·대시보드·배선 | PU foam, PP, PVC | 가연 |

> ⚠️ Steel은 HRR 기여가 0이다. 승용차 화재의 3~6 MW 피크는 대부분 **내장재 + 타이어**에서 나오므로, "차체의 연소 물성을 맞춘다"는 실질적으로 **내장재 인벤토리 튜닝**을 의미한다. (Okamoto 2009, Kang 2023 참조)

## 6. 공통 규약

### 6.1 시간
| 항목 | 규약 |
|------|------|
| `t=0` | 첫 셀 TR 개시 시점 (또는 히터 ON — 택일 후 메타데이터 명시) |
| 샘플링 | 급변 구간 Δt ≤ 0.1 s, 완만 구간 Δt ≤ 1 s (가변 허용, 단조증가) |
| 총 길이 | 0 ~ 3600 s 이상 (재발화 포함) |
| 포인트 수 | RAMP당 ≤ 5000 (FDS `NUMBER_INTERPOLATION_POINTS` 기본값) |

### 6.2 좌표계
차량 기준 (x: 전후, y: 좌우, z: 상하). 원점은 차량 하부 좌측 전방 코너. FDS 전역좌표 변환은 연세대 수행.

### 6.3 파일
```
KRISO_1D_output_<case_id>/
├── metadata.json
├── geometry.json
```
